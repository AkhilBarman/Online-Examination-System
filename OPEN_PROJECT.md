# 🚀 Open Online Examination System

Click any of the links below to open the application in your browser while the server is running:

- 🏠 **[Main Home Portal](http://localhost:8080/)** (`http://localhost:8080/`)
- 📝 **[Student Registration](http://localhost:8080/register.jsp)** (`http://localhost:8080/register.jsp`)
- 🔐 **[User Login](http://localhost:8080/login.jsp)** (`http://localhost:8080/login.jsp`)
- 🛡️ **[Admin Dashboard](http://localhost:8080/admin)** (`http://localhost:8080/admin`)
